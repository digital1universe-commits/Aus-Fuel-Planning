# Fuel & Holding — C208 in-flight fuel calculator

Phase Deck (in-flight hold / return / alternate decisions), Day Plan (multi-sector fuel ladder) and Descent Planning (TOD, profile and configuration gates), built to the company method in FOM Part A §6.4 and FCOM §7.1.1.

Install on an iPad: open the GitHub Pages address in **Safari** → Share → **Add to Home Screen**. After the first open it runs fully offline and autosaves on the device. Planning aid only — verify against aircraft indications and the current manuals.

Files: `index.html` (the app), `sw.js` (offline cache), `manifest.webmanifest` + icons (home-screen app). To ship an update, replace `index.html` and bump the cache name in `sw.js`.
